# 方法选择、表示转换与迁移

在学生“知道知识但不知道何时使用”、讲解关键选择，或训练新情境应用时使用。学生尚不具备必要知识时，先解释与示范，再逐步交还选择责任。

这里的选择包括公式、概念、模型、证据、论证方式、语言表达和操作方案。目标是从任务要求及材料关系作出合理选择，不要求所有问题立即想到唯一方法。

先按 [学科与任务适配](subject-adaptation.md) 确定当前要作出的选择及其证据。表格和示例不限制学科范围；一门学科可同时需要建模、实验取证与表达，随子任务切换。创作中可先探索再解释选择，不强迫先背“标准方法”。

## 从任务到可执行的第一步

用下面的过程组织示范与诊断，不把它变成每题必须回答的六问清单：

1. **明确目标。** 区分要求计算、解释、证明、比较、表达还是完成操作；确认输出与约束。
2. **提取关系。** 找数量、结构、因果假设、证据支持、语境或输入输出之间的关系，避免只按关键词匹配。
3. **尝试表示转换。** 必要时改写表达式、画图、列对照表、整理时间线、改述论点或追踪具体输入，使关系显露。
4. **提出候选。** 把可见关系连接到已学知识，提出一个或少数有依据的候选；不要求穷举所有方法。
5. **检查并比较。** 核对前提、限制和所缺信息，比较候选能否推进目标、是否简洁或适合语境。
6. **实际起步。** 完成关键改写、选择一条证据、写一个论证连接、说出合适表达或执行一步，并检查是否取得进展。

有时先试一步才能判断方法是否合适；允许有依据的试探与修正。学生已找到有效方案时，不要求倒回并补齐整张思考清单。

表示转换必须保留原任务的约束。改写方程时保留定义域；概括材料时不添事实；画经济模型时说明所用假设；修改语言表达时保留原意。

如果信息不足以支持选择，明确还缺什么，并允许条件式分析。不要用臆造数据、背景或证据让某个预设方法成立。

## 区分线索、条件与边界

- **弱线索**使一种方法值得考虑，但不足以确认适用，例如出现乘积、价格上升、两个事件先后发生或重复操作。
- **结构依据**说明为什么考虑某方法，例如同一量的一次项与平方项、表达式与其导数、主张与证据间的对应关系。
- **适用条件**决定当前用法是否成立，例如定义域、模型假设、证据范围、语境限制或算法的输入前提。
- **边界变化**可能使方法失效、需要调整或只是效率降低；分别说明，不把“不最简”说成“不正确”。

让学生对比“外观不同但关系相同”与“外观相近但关键条件不同”。初期一次突出一个变化，后续再引入组合；不要用尚未学过的新知识制造所谓迁移失败。

接受多个有效方案。开放论证、语言和设计任务按目标、证据、约束与表达效果比较，不把导师的偏好当成唯一标准。

## 准备一种方法的教学素材

按当前主题选用下列字段；无需每次向学生展示完整卡片，也无需建立覆盖所有知识的大型方法库。

| 字段 | 必须提供的具体内容 |
| --- | --- |
| 目标与前置 | 方法解决什么问题；学生需要先会什么 |
| 可见依据 | 学生能在题目或材料中实际找到哪些关系 |
| 隐藏形式 | 同一关系可能怎样改写、转述或换成另一种表示 |
| 第一项行动 | 怎样改写、组织证据、形成表达或开始操作 |
| 条件与边界 | 哪些假设需核对，哪些变化需调整或排除 |
| 易混候选 | 相近方法之间靠什么区别，何时都可行 |
| 示范与对比 | 一个有理由的示范、一个有区分力的变化或反例 |

示范时说清可检查的选择理由，例如“这两项能统一成同一个量”，避免“凭经验”“显然”或只报方法名称。理由必须能帮助学生下一次观察任务。

## 安排练习并撤去帮助

根据当前障碍选择下一项练习，允许跳步、返回或合并；不要求所有人按固定轮数完成全套：

零基础先教会一个可用概念或方法，再练适用与不适用；只有候选的必要知识已经具备时，才要求比较或无提示混合选择。缺乏目标时由导师选一个有意义的小体验，不让学生先猜自己需要哪种方法。

| 当前目的 | 可采用的任务 | 导师逐步交回什么 |
| --- | --- | --- |
| 理解选择依据 | 完整示范后解释一项关键决定 | 说明关系与方法的联系 |
| 学会区别候选 | 比较少数方法，指出依据与排除理由 | 判断条件，而非猜方法名 |
| 识别隐藏结构 | 同关系的新表述、图形或表达式 | 自行完成必要表示转换 |
| 避免过度套用 | 外观相近但条件不同的对比任务 | 判断失效、需调整或仍可用 |
| 自己产生方案 | 无选项任务，提出方案、理由和第一步 | 形成候选与开始行动 |
| 在混合任务中应用 | 混入已经学过的概念或方法 | 从任务本身决定采用什么 |
| 检查完整应用 | 完成求解、论证、表达或操作 | 连接选择与后续执行 |

只练选择时，可以暂不完成全部计算或写作，借此隔离识别障碍；随后仍需完整任务检查所选方案能否成立并推进。说出术语不等于会应用。

练习初期可以给选项、结构提示或局部示范，但应记录这些帮助。后续撤去的应是已由学生接手的责任，不是单纯让题目越来越长。

刚讲过某方法，紧接的新题仍受上下文提示。有关无标签混合任务、独立条件、延迟检查与证据限定，使用 [检测、评分与复习](assessment-and-review.md)，不由一次选对推断普遍迁移。

## 跨学科的简例

以下例子说明怎样连接依据与动作，不是要求逐一讲授的固定题库。

### 数学：把隐藏结构显露出来

对 `4^x - 5·2^x + 4 = 0`，关键改写是 `4^x = (2^x)^2`。两项可统一为同一个量的平方与一次项，因此令 `t = 2^x > 0`，得到 `t² - 5t + 4 = 0`。

解得 `t = 1` 或 `4`，回代得 `x = 0` 或 `2`。选择依据是二次结构及替换条件，不是“看到指数就换元”。

可用 `e^(2x) - 5e^x + 4 = 0` 练同结构换表示；再比较 `4^x - 5·3^x + 4 = 0`，只要求判断能否直接照搬刚才的二次替换，无需要求立即解出新方程。

对链式法则，先识别运算层级；对积分选法，比较 `∫2x cos(x²) dx` 中内层及其导数的关系与 `∫x e^x dx` 中求导简化、易积分的关系。乘积外观本身不决定方法；接受其他有效解法。

### 经济学：从变化因素选择模型

“价格上升”不足以推出需求曲线移动。先明确是研究商品本身价格变化，还是收入、偏好等条件变化，并核对其他条件如何保持。

练习先让学生选择要分析的变量与关系，再画图或解释方向。换一个情境检验时，避免在题目标题直接写“需求曲线移动”。复杂情境可有多个变化，不强迫只选一条曲线。

### 论证与阅读：让证据对应结论

材料显示两个变量相关时，先区分“存在关联”与“前者导致后者”这两个主张。让学生指出材料直接支持什么、因果解释还需什么依据，必要时收窄结论。

对比另一段研究或史料时，可以改变证据质量、来源视角或覆盖范围，让学生调整主张强度与论证方式；不要把某个连接词当成证据充分的标志。

### 语言：根据意图、对象与场景选择表达

练习请求、拒绝或说明理由时，先确定沟通目的、双方关系与场景，再比较语气、语域和明确程度。给初学者必要词汇与示范，避免让词汇缺口掩盖语境理解。

后续换一个对象或场景，让学生自行组织表达并解释一项选择。允许多种自然表达，不把背出示范原句当作迁移。

## 选择失败后的修复

不要一律重讲公式或整章内容。若点明方法后能继续，优先修复识别；若想到方法却无法整理材料，修复表示转换；若条件不成立，练边界判断；若第一步合理但后续卡住，转向推理或执行支持。

具体诊断与教学路线使用 [分单元教学](teaching-flow.md)。给出关键线索后成功，只能说明帮助恢复了进展；在适当的新任务中撤去该线索，才能继续检查学生能否自己作出选择。
