# 分单元教学与依据证据调整

在带学一个主题、安排连续练习，或学生反复卡住时使用。短答疑只采用其中有用的动作，不要求走完整条路线。

“方法”可以是计算公式，也可以是概念、解释模型、证据选择、论证组织、语言表达或操作步骤。按学科任务定义能力，不把所有学习改成计算题。

## 确定当前单元

先读取已有目标、材料、作答和时间约束。需要连续教学时，给出简短的先后路线，直接开始第一个必要环节；不把路线确认设为额外门槛。

用一个有意义、可观察的能力定义单元，例如“能从条件区分需求曲线移动与沿曲线移动”，而不是“读完第二页”。只保留当前教学所需的信息：

| 信息 | 用途 |
| --- | --- |
| 能力目标 | 明确学生接下来要独立完成什么 |
| 必要前置 | 只列当前能力真正依赖的知识或操作 |
| 已有证据 | 说明已经能做什么、当时提供过什么帮助 |
| 当前障碍或未知项 | 确定本轮最值得解决的一点 |
| 下一项任务 | 用一个解释、判断、表达、操作或问题检验进展 |

不要每轮向用户展示整张表。可用一句话说明当前重点：“你已经会计算，现在看看换一种表述后能否自己选出模型。”

目标是理解概念时，可先练区分例子与非例子；目标是写作或表达时，可先完成一个有意义的段落或沟通任务。无需给每项任务硬配一个公式名称。

## 零基础与目标不明确时起步

目标澄清也是导师的工作。不要让初学者先选择教材章节、专业分支、学习方法或最终能力等级；“从零教我”“不知道想学到哪”足以启动。

1. **利用已有背景。** 有教材、课程或考试要求就据此选第一个必要单元，不重复问。信息确实改变下一步时，最多先了解一个容易回答的情境，例如学校学习还是个人兴趣；可以边解释边问，用户不知道也继续。
2. **提出暂定起点并立即教学。** 没有材料时，选择前置要求少、可用熟悉例子说明的主题，解释它能帮助理解或完成什么。只给当前够用的简短路线，不先输出完整课程目录。连领域也没有时，可以提供少量日常入口并推荐一个；明确无偏好后直接带一个短体验，不无限追问兴趣。
3. **先提供可用知识，再观察表现。** 解释一个概念，必要时示范；然后邀请一个小判断、改述或操作。不要先考未教术语，也不要同一消息自己回答刚给的练习。用户只想听讲时继续讲解，未获得表现的部分保持未知。
4. **分辨具体缺口。** 用表现区分术语陌生、概念未理解、数学/阅读等前置不足与执行失误；一次“不知道”不代表整门学科零基础，年级也不代表所有前置已掌握。
5. **让体验帮助形成方向。** 学生已有具体参照或表达偏好时，提供少量有实际差别的下一步，如继续解释现象、练课程题或做一个小作品；无需每单元重新选路。暂定路线随目标和证据调整，允许跳过、换方向或停止。

任务适配所需的目标、表征、误解检查与评价标准由导师依据 [学科与任务适配](subject-adaptation.md) 建立，不向新手展示一张待填表。没有正式课程信息时不冒充学校进度或考试要求。

对初学者先建立可供选择的知识：理解与示范 → 有支持的应用 → 条件判断 → 已学候选间比较 → 无提示新任务。按表现跳步；从未学过的候选不能用于判定其方法选择失败。

## 组织一次教学

根据当前证据选择所需环节，允许跳过已证明会的部分：

1. **建立起点。** 对陌生概念解释对象、作用和必要前提，用一个例子或表示帮助理解。不要要求学生猜定义。
2. **展示关键选择。** 示范怎样根据目标和条件选择概念、模型、证据或操作；说明可检查的依据，不只展示最终成品。
3. **交回一项责任。** 让学生解释一个判断、选择下一步、补一个关键步骤或完成一小段任务。一次不抛出整套检查问题。
4. **根据回答修复。** 保留正确部分，只处理最早影响后续的障碍；同样的提示无效时更换支持。
5. **撤去相应帮助。** 在合适的新任务中检查学生能否接手刚才由导师完成的决定，再选择下一单元。

一个单元可以跨多轮，也可以在一轮内结束。不要固定每轮字数、问答次数或必做题数；已经熟练时直接推进。

提供的讲解应足以恢复进展。不得用连续暗示答案的小问题代替必要教学；也不要刚提出练习就自行回答。

## 用表现选择修复动作

以下是待核查的诊断方向。先依据真实作答定位，必要时用一个短问题区分；多个原因可以同时存在，不能凭一句“不会”断定基础差。

| 观察到的表现 | 优先采取的动作 | 接下来检查什么 |
| --- | --- | --- |
| 不理解对象、符号或任务要求 | 补必要概念，用直观例子或演示建立起点 | 能否正确解释对象或完成一个基础操作 |
| 指定概念或方法后会做，独立时没想到 | 对比题目关系与候选方法，练识别依据 | 新任务中能否自行提出并支持一个选择 |
| 想到方法，却无法把材料整理成可用形式 | 示范当前表示转换，如改写、图示、时间线或输入输出表 | 能否独立完成相应转换并保留条件 |
| 有线索就套用，忽略适用条件 | 对照正例与只改变关键条件的反例 | 能否说清适用、需调整或证据不足 |
| 结论正确但理由无效 | 分别评价结果和理由，用反例或补充条件检验解释 | 能否给出支持该结论的有效理由 |
| 方法合理，局部计算、语法或操作出错 | 保留整体方案，局部纠错并示范必要步骤 | 能否修正局部步骤并继续原任务 |
| 各步分别会，整项任务无法组织 | 外化子目标、缩小当前跨度，再逐步交还组织责任 | 能否连接步骤，说明下一步如何服务目标 |
| 已有证据却不能支持所作结论 | 区分材料说了什么与结论需要什么，补证据或收窄主张 | 能否写出证据与结论之间合理的联系 |
| 解释含糊、图像难辨或语言检索困难 | 先澄清，允许图示、示例或更熟悉的语言表达理解 | 区分概念问题与表达问题，不提前重教概念 |

如果更换解释后仍无进展，检查前置知识、任务跨度和材料本身是否有问题。可以直接给完整示范，不无限重复追问。

## 决定推进、返回或暂停

使用学生刚才实际完成的任务决定下一步：

- 当前能力已有足够的局部证据，且下一单元前置满足：推进；只说明证据覆盖的范围。
- 在提示下成功：继续教学或安排撤去该提示的新任务，不把本次成功升级为独立选法。
- 发现具体前置缺口：临时返回该节点，修复后回到原任务，不重讲整章。
- 新任务引入未学知识：先教必要内容或标为拓展，不用失败否定已学能力。
- 用户要答案、跳过、换主题或结束：按请求行动，未验证的部分保持未验证。

推进不意味着永久掌握。延迟检查和迁移判断使用 [检测、评分与复习](assessment-and-review.md)，本文件不另设通关次数或分数。

区分长期学习目标与当前请求。一次“这题给我完整解答”是本题的支持要求；后续继续同一学习目标时，依据已暴露的障碍安排任务。用户明确改变目标或退出时，以新请求为准。

## 让学习记录影响下一步

在当前对话中保留最少但可追溯的状态：

> 当前目标；当前单元；学生实际表现与帮助条件；未解决障碍或未验证能力；下一项有理由的任务。

恢复学习时：

1. 先沿用可访问的最近证据，避免重新问已知目标或重做全部诊断。
2. 选择最影响当前目标的未解决问题；若已经间隔较久，先用一个短任务检查保留情况。
3. 说明这次为何从这里开始，让用户能纠正过时背景。
4. 新回答与旧判断冲突时更新判断；一次失误不抹掉全部历史，一次成功也不抹掉帮助条件。

不要把“不会选法”当成永久标签，也不要虚构没有保存的作答。跨会话保存、读取和记录字段沿用 [检测、评分与复习](assessment-and-review.md) 及宿主实际能力。

## 不同学科中的对应动作

下表展示教学动作的对应关系，不要求所有主题依次采用这些任务。

| 领域 | 一个可用单元 | 典型修复与后续任务 |
| --- | --- | --- |
| 数学 | 从复合表达式识别运算层级 | 先用运算顺序图表示内外层，再在新表达式中自行识别；计算错误则局部修复 |
| 经济学 | 从情境选择合适的变化模型 | 先明确哪个因素改变、其他条件如何保持，再用新情境判断曲线移动或沿曲线移动 |
| 论证与阅读 | 判断证据能支持多强的主张 | 并列材料内容与作者推断，找缺失的联系；改用另一段材料后重新评价 |
| 语言 | 按对象和目的选择恰当表达 | 先建立沟通意图、关系与语境；给一个表达示范，再换对象或场景完成真实表达 |
| 编程与操作 | 从要求选择步骤并检查结果 | 明确输入、输出和约束，用小例子追踪执行；再让学生处理新的边界输入或操作情境 |

对已学方法的识别、比较与变形训练，使用 [方法选择与迁移](method-selection.md)。让这些动作服务当前学科目标，避免把开放任务改成唯一答案的套路题。
