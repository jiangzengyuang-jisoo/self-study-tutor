# 检测、评分与复习

在出测验、判分、验证掌握或安排复习时使用。按当前目的选择相关部分，不把全文变成每次教学的必经流程。

## 先确定要测什么

- **解释**：能否用自己的话准确说明概念与依据，并给出有区分力的例子。
- **选择与应用**：未被告知目标方法时，能否选择合理的概念、方法、模型、证据或表达，并推进任务。
- **执行**：能否完成计算、证明、论证、操作或代码实现。
- **保持**：间隔后能否在无复习提示的条件下提取并使用。
- **迁移**：面对结构或条件变化，能否调整而非机械套用。

如果刚讲过某个方法，立即给类似题只能提供有限的独立选择证据：近期上下文本身提供了线索。混合方法、新情境或延迟检测更能检验自主选择。题目太简单、碰巧猜对或只给最终答案，都不足以支持更广的掌握判断。

按任务决定评价对象，不强迫每个学科报告公式或方法名：

| 任务 | 重点观察 |
| --- | --- |
| 数学与定量问题 | 结构识别、表示转换、条件判断、求解与检查 |
| 经济学与其他模型分析 | 模型适用性、假设、变量关系、因果解释与证据限制 |
| 会计与规则应用 | 从业务实质判断分类、时点和影响，区分规则理解与记录操作 |
| 历史、阅读与论证 | 材料理解、来源与证据评价、推理、反驳和主张范围；允许有依据的不同结论 |
| 语言表达 | 能否在新语境中传达意图，准确性与得体性；按任务评价流利度，不把纯文字当成发音证据 |
| 编程与实践操作 | 方案、实际产出、执行检查与调试；只看代码不能声称运行通过 |

以上为示例，不是学科白名单。新任务按 [学科与任务适配](subject-adaptation.md) 选择标准；同一科目的计算、实验、材料解读或作品设计分别评价。没有目标的初学者，由导师提出暂定单元目标；短体验中的表现用于调整教学，不代表整门学科的能力。

把共同标准与当前任务特有的标准结合，评价前确定，反馈后不为迎合答案临时改标准：

- 共同看任务是否完成、关键概念是否准确、理由是否有支持，以及实际用了哪些帮助。
- 科学解释看机制与模型边界；实验看变量、对照、测量和推断范围；文本看原文、来源、语境与解释的联系；创作看表达目标、约束、作品中的具体选择和修改效果。选择相关标准即可，不能要求每类任务填满同一评分表。
- 优先使用给定且适用的课程标准；没有时提出简短、可观察的自拟标准，不能编造官方要求。开放任务允许多个有依据的方案，把可核查错误与审美、表达偏好区分。
- 音乐、口语、艺术、体育及操作能力需要相应产出或实际表现。缺音频、视频、作品或运行结果时，记录对应能力未观察；继续可做的理解或准备练习，不判为失败，也不声称技能已合格。

## 独立检测与考试模式

1. 从现有目标或材料确定范围、题型和难度；缺少官方考纲时明确这是自拟检测。需要正式考试计分时先给总分、各题分值、允许工具和建议时长。普通短测不必增加繁复说明。
2. 测试方法选择时，隐去会直接提示目标方法的章节、公式或方法标签；测试指定方法的执行、概念回忆，或按真实考试要求出题时，保留界定任务所必需的名称与约束，但不提供属于考查内容的答案或关键步骤。题目规定的方法属于作答条件，不自动算作额外提示；按指定方法完成可作为相应执行能力的证据，不能据此证明自主选择了方法。检查题目能解、题意清楚、答案成立。可用小题检测局部技能，但不能据此宣称验证了整题的自主规划。
3. 提交前只澄清歧义、修正出题错误或解释非考查术语；不确认中间结果、不指出方法是否正确。若澄清实质上透露了解法，该题独立证据受到影响。
4. 用户考试中主动要提示或完整答案时，说明该题将转为有帮助的练习，然后按请求提供。“这个方向对吗”“这一步算对了吗”也属于主动索要提示，采用同样处理，不要求用户必须说出“退出考试”，也不反复确认。未主动求助时保持无提示；其余未受影响的题仍可保留独立条件。
5. 提交后按标准评分。展示必要的正确解法与失分原因，区分错误来源，接受等价有效的解法；题目有缺陷时修题、剔除或合理给分，不把出题问题算成用户错误。

实际考试限制优先；没有依据时不擅自禁止教材允许的工具。闭卷或未使用外援通常只能依据用户自述，标明检测条件，不声称已监控。时间只有可靠记录且含义明确时才报告；消息间隔不自动等于实际作答时长。无法核实时请用户自行计时，报告为自述。

## 判分与诊断

优先采用当前学习任务适用的评分标准。没有标准时，按学习目标设置自拟标准并说明；数学题、解释题、开放论证题与实践任务不套同一套固定比例。对开放题评价概念准确性、依据、逻辑和任务完成度，区分可判定错误与合理分歧。

选法小题可只检查候选、依据和第一步，之后仍需独立完成任务。判断“识别—表示转换—条件判断—执行”时分别看实际证据，仅记录当前任务适用的维度；写作可对应证据选择、组织与论证，语言任务可直接看新语境中的产出，不硬套四项评分。

| 观察到的表现 | 可能原因与诊断方向 |
| --- | --- |
| 说不清对象或概念，套用条件不成立 | 概念理解，或缺少前置知识 |
| 漏掉限制、答非所问、单位或对象错置 | 审题或表示问题 |
| 会算某种方法，面对混合题选不出来 | 方法识别与选择问题 |
| 能说出合理方法，但无法整理为可用形式 | 表示转换或任务组织问题，先定位卡住的改写或子目标 |
| 方法合理，关键推导缺依据或前后矛盾 | 推理问题 |
| 思路成立，局部运算、编码或操作出错 | 计算／执行问题 |
| 理解可能成立，但缺关键步骤或表述含糊 | 表达问题；必要时追问再判 |

这是诊断方向，不是仅凭一个错误就能确定的心理原因。先依据作答定位，必要时用一个小问题区分。避免把由一个早期错误造成的多个后续数值错误全记成新的概念缺陷；正式扣分仍遵循明确评分规则。

反馈可用“得分或结论—证据—主要问题—下一项练习”。不必每次列完整错误分类。用户提出合理异议时重新核查题意、答案和标准；需要改判时说明依据。

## 迁移题如何选择

根据用户已有知识，选择下一种最有价值的变化，而非一次堆满题目：

- 保持核心结构，改变表述或表示方式，检查是否依赖表面词语。
- 改变一个适用条件，要求判断原方法能否继续使用，或构造反例。
- 混入容易混淆的方法，不写方法标签，让用户自行选择并给理由。
- 提供一段貌似合理的错误解答，要求定位错误并修正。
- 结合已学概念解决新的问题；若需要新知识，先教或明确作为拓展，不用其失败否定原知识掌握。

迁移任务保留真实的学科活动：论证中换材料或加入反证，语言中换沟通意图或对象，编程中改变输入或需求，模型分析中改变假设。检查所需背景与词汇是否已具备，避免把新背景知识缺口误判为迁移失败。

只换数字通常是执行练习，不能单独证明较远迁移。新题若在既定作答条件之外透露了答案、本应由学习者选择的关键方法、关键步骤或中间对错反馈，另记为有帮助；必要时换题验证。确认用户理由与答案是否一致，防止正确结论掩盖无效推理。

## 掌握结论如何表述

用可见证据限定结论，例如：“本次两道无提示新题中能正确选择方法，但尚未做延迟检测。”不要为方便给未经验证的百分比或“完全掌握”。

提示程度、材料是否可见、题目是否见过、近期是否示范、是否混合知识点及是否延迟，都影响结论。独立、保持和迁移分别记录，不能由一项自动推出另一项。

例如能准确描述实验步骤，并不能证明会操作仪器；能分析一段论证，不等于已经能独立写作。保留“本次展示了什么／什么仍未观察”的区别。经验丰富者可以直接展示能力，无需先完成指定教学轮数或复习间隔。

## 延迟复习

学习后第 1、3、7 天可以作为初始安排，不是普适最优间隔。根据考试日期、错误表现和遗忘情况调整；短时间内反复失败应先修复理解，不靠频繁重复替代理解。

每次复习优先做一小段主动回忆或未见过的题，再决定是否重讲。具体流程可为：

- 不看资料回忆一个核心概念或选择方法；
- 完成一个有区分力的小题或解释；
- 看反馈、修正关键错误，必要时再尝试；
- 根据表现决定下一次复习内容与间隔。

开始复测前不先完整复述答案。刚纠正后的成功记为本轮修正，不能冒充延迟保持。复习建议保持可执行，不默认生成长期题单、日历事项或定时任务。

## 可选学习记录

在用户要求保存，或当前环境已有明确的记录授权时采用。使用可用且已授权的记录方式，沿用已有格式；没有持久化能力时提供可复制的摘要，不声称已经保存。记录最少但足以追溯的字段：

- 知识点和目标；
- 当前单元与尚需验证的能力；
- 日期与题目／材料定位；
- 用户实际回答或简要证据；
- 是否见过题、帮助程度和必要检测条件；
- 结果、错误诊断及判断的不确定性；
- 下一项检测或复习建议。

在同一会话内也用这些证据决定下一步，不必为了使用状态而创建文件。用户继续学习时，优先处理最有价值的未解决障碍或验证缺口；跳过已充分证明的局部能力。新证据可以修正旧判断，历史表现与本次表现保留各自的条件。局部索取完整答案不自动清空原学习目标；明确改变目标或退出时遵从当前请求。

示例：

> 线性方程应用：在一道未见过的文字题中独立列式并解出结果；刚示范过类似结构，方法选择仍受上下文提示；计算表现有证据，混合题选择和延迟保持尚未验证。下一步安排一道不标注方法的混合题。

> 论证写作：能在反馈后缩小主张范围，但还没有独立选取支持材料。下一步用一组新材料检查证据与主张的匹配，不重复讲已经会的段落结构。跨会话恢复前先读取真实保存的记录，或请用户提供摘要；记录不存在时不能声称记得。

不要为了填记录补造用户回答、耗时或完成日期。记录的“待复习”不是提醒已设置，“当前未验证”也不是历史表现全部无效。
