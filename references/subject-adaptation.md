# 学科、任务与证据适配

新领域、新任务或示例不足时使用。按当前能力目标选择相关部分；学科名单不限制适用范围，不把全文展示给学生。

## 建立当前适配

从已有对话、材料、作答与作品提取信息。由导师整理，学生只补充影响下一步且能回答的缺口，不做入门问卷。

| 信息 | 对教学的影响 |
| --- | --- |
| 学科与当前主题 | 决定对象、概念、约定及需要核查的专业内容 |
| 课程与使用情境 | 有教材或考试要求时沿用其范围；兴趣探索时采用可调整的起点 |
| 学习任务 | 区分解释、计算、证明、取证、解读、表达、设计和实际操作；可以组合 |
| 当前基础 | 使用已观察到的能力；年级、自称零基础和术语熟悉度都不能替代实际表现 |
| 当前可观察目标 | 写成学生能完成的动作，如“用材料支持一个有限主张”，避免只有章节名 |
| 表征与必要工具 | 选择有助于当前障碍的图、文字、符号、数据、声音、代码或作品 |
| 评价依据与缺口 | 区分课程标准、可靠领域依据与本次暂定练习要求；注明尚未观察到的能力 |

信息够安排下一步即可；变化时局部更新，不重新访谈。

同一学科可以有多种教法，如化学计量、机制解释和实验设计。跨学科任务可组合策略，先处理当前主要障碍。

## 选择任务策略

按课程、阶段和任务组合下列策略，无强制顺序；短答疑不必附加练习。

| 当前任务 | 适合的教学动作 | 可观察的成功表现 |
| --- | --- | --- |
| 形式推理、证明与计算 | 明确对象、定义、前提与关系；按需要转换表示，示范关键推理并核对边界 | 结论与推理均成立，条件未丢失；能够解释关键步骤，接受有效的替代解法 |
| 定量建模与物理解释 | 明确系统、变量、条件及过程阶段；需要时先定性预测，再连接图像、关系式和计算 | 能从条件选模型，说明假设，并用单位、极限或数量级等相关检查验证结果 |
| 机制与过程解释 | 连接现象、机制及符号；化学关注宏观—粒子—符号关系，生物按问题连接结构、功能、调节或不同尺度 | 能解释结果如何产生，预测条件变化的影响；不只复述名称 |
| 实验、调查与数据分析 | 明确问题、变量、测量、比较方式与限制；分开观察、推断和因果解释 | 数据处理与设计相符，结论强度与证据相称；能指出一项实质局限或改进及其作用 |
| 文本、史料与论证 | 回到材料，辨认来源、语境和目的；必要时互证，区分事实、解释和价值判断 | 主张有依据，解释证据与结论的联系，处理反例；接受有支持的不同解释 |
| 语言理解与交流 | 结合意图、对象和情境，提供所需词汇或结构；在可处理的输入与实际表达之间转换 | 理解或表达完成沟通目标，语域适合；反馈区分意义、准确性和自然度，不要求照背示范 |
| 编程、算法与技术操作 | 明确输入、输出及约束；按需追踪、小规模执行、构造边界例或检验不变量 | 方案满足要求，能解释关键选择并验证结果；区分运行成功与理解原因 |
| 工程设计与艺术创作 | 明确需求或意图、受众、媒介与约束；分析具体决定，再尝试和修改 | 产出体现目标，能说明取舍并修改；区分技术问题、约束违背与审美偏好 |
| 演奏、发音、运动与实践表现 | 拆出可观察动作，结合示范与真实反馈；使用可用的音频、视频或操作记录 | 实际表现满足目标；文字解释与真实完成分别判断，未观察的维度保持未知 |

不要求所有力学题画受力图、所有概念先做实验、所有公式完整推导或所有创作遵循唯一范式。每个动作应解决当前具体障碍。

选择训练可涉及公式、模型、证据、表达或操作策略。必要基础具备后才安排无提示选择，允许试探、组合和修正。

## 没有专用参考的学科

没有专用示例时，由导师完成简短适配：

1. **定位任务。** 从请求及材料判断要完成什么。目标模糊时提出暂定起点，按下一节开始。
2. **建立最小目标。** 定义当前一项可观察能力及必要前置，不要求用户先选知识点。
3. **选择表征和策略。** 从上表选动作并按领域调整；不熟悉的术语、约定和事实依据可靠材料核查。
4. **确定评价依据。** 有评分标准就采用；没有时形成可核查的暂定要求，不能称其为官方、行业统一或唯一标准。
5. **开始并修订。** 给必要解释或示范，依据表现更新判断和下一步；不以完整材料为一般性开课条件。

材料缺失、来源冲突或专业知识不确定时，明确缺口并按需要查证；可先教有可靠依据的部分，不能编造关键条件或标准答案。

课程任务核对给定材料，疑似错误仍需查证；研究、技术或时效性问题使用适合的原始资料与官方文档。只引用实际读到的位置。

遇到新材料、任务或反例时更新适配，不把一次成功固化为整门学科的教法。

## 目标不明与零基础

“我完全不会”“不知道要学到什么程度”是可接受的起点。路线设计和评价标准主要由导师承担，不能让新手先回答专业需求问卷。

- 有学科、无目标：选一个前置少、有意义的小单元，说明可调整并直接开教。有课程则按可用材料起步，不虚构考纲。
- 学科未定：给少量通俗的体验方向；仍无偏好时说明一个暂定短体验并开始，允许更换，不让菜单阻塞教学。
- 对未知概念先教，再用小任务观察基础；区分概念、语言、数学工具或操作缺口，局部补足，不以猜不出未教术语判能力差。
- 学过少量内容后，结合实际体验提出具体后续方向；不必每单元重新询问目标。

起步说明路线后立即进入实质教学，不只发计划和承诺。

尚只认识一种方法时，可练理解和适用条件。已有相关候选后，再练区分；初学者需要的知识和示范不能被“训练独立选择”省略。

## 用误解检查改变教学

下列表现只是诊断线索。用小任务区分原因，观察后再修复；必要知识未教时先解释。

| 可见表现 | 区分性检查 | 依据回答采取的修复与后续检查 |
| --- | --- | --- |
| 会背公式，换场景就任意套用 | 说明对象、条件与所求量，区分识别困难与概念缺口 | 识别困难练条件与候选的联系；缺概念先示范。换场景检查选择及起步 |
| 化学方程写对，却把系数解释为粒子的大小变化 | 用课程允许的简单粒子图，让学生对应符号和数量 | 修复符号与粒子数量的联系，再用另一种表示检查；不要仅增加配平练习 |
| 生物术语都认识，解释只有“为了……” | 描述什么变化通过什么过程影响下一环节 | 分开功能与机制，补因果联系，再预测条件变化；不必跨越全部尺度 |
| 图表显示差异，就直接断言某因素造成结果 | 检查比较如何形成、是否还有其他变化或解释 | 若数据读错先修读图；若因果跳跃则补设计与证据边界，再调整结论或提出所需证据 |
| 史料立场鲜明，就判完全无用或可信 | 它能帮助回答哪个问题、不能单独证明什么 | 分开来源视角、记载内容和研究问题；互证或限定结论，不用“有偏见”淘汰材料 |
| 语言理解正确但不能独立表达 | 检查词句、语境还是组织缺口，允许先用熟悉方式说明意图 | 给局部支持，换熟悉场景尝试；文字成功不能推断发音和流利度 |
| 代码或操作照做成功，改一个输入就失败 | 让学生预测一个小输入或条件变化的结果，并核对实际步骤 | 定位边界、步骤理解或验证缺口；修改后用能触发该问题的新案例检查 |
| 创作反馈只剩“好看／不好看” | 对照学生意图与作品中的一个具体选择，说明它产生什么效果 | 给出可尝试的局部修改和比较依据；允许不同风格，不以导师口味判错 |

后续检查不悄悄增加未教知识。核对并接受有效的其他路径或解释，不因偏离预设答案重复纠正。

## 按任务评价并保留证据

评价前明确可观察的要求，不为迎合回答或预设结论改标准。题目有缺陷或出现合理替代解法时可修订，说明原因并重新评价。

共用的证据问题是“学生在什么条件下实际完成了什么”，具体标准采用上表相关部分。没有音频不能评分发音，没有动作记录不能确认运动技术；继续教可核查的部分，说明尚待观察什么。

分别保留本次独立完成、受助完成、陌生情境表现和延迟保持的证据；这些不是必须按顺序通关的等级。没有测过的能力标记未验证，不用“整体掌握度”平均掩盖关键缺口。

反馈指向具体内容及缺口，如“结论与数据对应，但设计还不能排除另一解释”。详细检测与记录沿用 [检测、评分与复习](assessment-and-review.md)。

规则执行不证明教学有效。观察撤去帮助后的表现，并把模型模拟、行为检查与真实学习结果分开。
