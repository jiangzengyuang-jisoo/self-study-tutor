## 如何运行

每个场景和条件使用独立新会话（未继承前文）；A 为宿主默认指令，B 增加 [评测说明](../../README.md) 中的固定短提示，C/D 明确要求读取各自运行时目录中的技能及相关参考。各条件使用同一父模型继承设置，但精确模型版本及采样参数未公开，不能视为严格固定的统计实验。

运行时副本不含评测文件。目录范围同时通过任务指令限制，但不是强制的文件系统隔离。本报告保留学生消息和最终回复，没有附完整工具调用轨迹；因此不据此独立验证实际宿主的自动发现或注入机制。

后续消息只在此前解释满足投递条件时发送。没有因为导师给出了不同的练习就捏造学生答题；学生按脚本请求转向或结束时，保留原请求。对话结束后另行归档可见消息，归档要求不计入教学对话。

## 观察到的行为

| 场景 | 改版实际表现 |
| --- | --- |
| 零基础导数 | 给简短路线，从平均变化率开始；学生仍混淆函数值时，用水量与升每分钟的区别局部补讲 |
| 链式法则理由错误 | 区分保留内层的值和内层变化率；没有把解释后补因子认定为迁移通过 |
| 隐藏二次结构 | 提示底数关系后交回改写；后续明确指出受助完成及近期上下文限制 |
| 混合积分与退出检测 | 提供三题且不泄露逐题方法；用户要求停止测试后给出完整有效解法 |
| 需求与需求量 | 根据变化因素区分沿曲线移动与曲线移动；偏好变化后重新检查同价下数量 |
| 配额牌照租金 | 先核对配额约束生效，再区分销售收入与牌照租金；得到每张 20、总计 400 |
| 应计利息 | 确认金额与贷方，只修本金负债与利息费用的分类混淆 |
| 根据记录继续 | 使用用户提供的记录，直接处理预收收入；停止请求后只给一句下次建议 |
| 论证证据 | 检查相关到因果、自愿到强制、平均到每个人的推断；接受有依据的收窄主张 |
| 英语时态 | 解释时间段与现在的关系，纠正按 `for two years` 关键词固定选时态 |
| 直接改写与承接 | 直接给完整英语改写和一句理由，随后用一句话记录尚待验证的独立表达 |
| 未提供具体示范的编程任务 | 按循环次数依赖关系分析；区分宽松上界 `O(n²)` 与紧界 `Θ(n)`，新例子不同时给答案 |

上述“观察到”只描述这些输入下的输出，不代表其他模型、用户或题目也会稳定如此。编程仅是在本仓库没有提供对应具体教学示例；不意味着模型训练中从未见过相似问题。

## 两组四条件对照

数学场景中，四种条件都能识别二次结构并否认“一题提示后成功即可证明所有变形题都会”。A/B 首轮直接给出平方关系与替换变量，C/D 留下部分改写让学习者完成。C/D 后续都明确指出刚讲过方法会提供上下文线索；这不是改版独有的行为。

论证场景中，四种条件都能定位观察与因果推断的缺口，接受合理修订，并将可能的选择差异与已知事实区分。各组在是否立即给另一道练习、先示范还是先追问上不同，但这些单次差别不足以建立教学效果排名。

盲评在适用维度上均给出 2 分，未发现阻断问题；这说明本轮案例主要覆盖了基本正确行为，也提示当前量表对这些较强回答的区分力有限。不能用这些满分给版本排序。

本轮没有证据支持“只要加载改版就会明显超过默认模型”的结论。更有价值的下一步是围绕不同错误理由、连续学习和撤去帮助后的真实学生产出继续比较；若一个新增模块只增加篇幅，应删减。
